### 📍 **Seating Management System** — Exam Allocation Platform
![Live](https://img.shields.io/badge/Status-Live-brightgreen) ![Production](https://img.shields.io/badge/Environment-Production-blue)

**Real-world impact**: Deployed at Mewar University for 500+ students  
**Live Demo**: [seating-management.vercel.app](https://seating-management.vercel.app)  
**Repository**: [GitHub](https://github.com/MohammedHashimNilger/Seating-Management)

**Problem**: Manual exam seating allocation consumed 2+ hours per semester for large student batches.

**Solution**: Automated allocation system with intelligent conflict detection and real-time synchronization.

**Tech Stack**: React • JavaScript • Node.js/Express • MongoDB • Vercel

**What I Built**:
- Conflict detection algorithm ensuring no scheduling overlaps
- Real-time data synchronization with Supabase
- Role-based access control (admin/supervisor/student)
- CSV bulk import for 500+ student records
- Printable allocation reports in PDF format

**Impact**: ✅ Reduced allocation time from 2 hours → 15 minutes | ✅ Zero scheduling conflicts

### 🏆 **Resume Craft AI** — AI-Powered Resume Builder & ATS Analyzer
![Live](https://img.shields.io/badge/Status-Live-brightgreen) ![SaaS](https://img.shields.io/badge/Type-SaaS-orange)

**Live Demo**: [resume-craft-ai-v2.vercel.app](https://resume-craft-ai-v2.vercel.app)  
**Repository**: [GitHub](https://github.com/MohammedHashimNilger/Resume_Craft)

**Problem**: Job seekers lose hours formatting resumes; 75% of applications rejected by ATS due to poor keyword matching.

**Solution**: Full-stack SaaS platform generating professional resumes and analyzing ATS compatibility in real-time.

**Tech Stack**: React • Node.js/Express • MongoDB • Groq AI API • Tailwind CSS • Vercel

**What I Built**:
- Secure JWT authentication with session management
- Resume CRUD with 5+ professional templates
- Real-time ATS score calculation and keyword extraction
- AI-powered resume enhancement using Groq/LLaMA-3
- PDF export with formatting preservation
- Mobile-first responsive design

**Key Achievement**: Optimized PDF generation by moving client-side rendering to backend service — **reduced load time from 5s → 1.2s**
